# AGENTS.md

Terraform module that runs [Atlantis](https://www.runatlantis.io/) on AWS Fargate.
The root `*.tf` files are the module, `modules/` holds its submodules and
`examples/` holds usage examples. The inputs and outputs tables in `README.md`
are generated by the `terraform_docs` prek hook, so do not edit them by hand.

## Validation

Run `just --list` to see the recipes. They need `terraform`, `terraform-docs`,
`tflint` and `prek` installed.

| Command | What it does |
| ------- | ------------ |
| `just lint` | Runs the prek checks that never rewrite files (`terraform_validate`, `terraform_tflint`, `check-merge-conflict`) |
| `just format` | Runs `terraform fmt -recursive` |
| `just format-check` | Fails when `just format` would change something |

There is no `just build` or `just test`: the module has no build step and no
automated tests. To run every prek hook, including `terraform_docs`, use
`prek run --all-files`.
